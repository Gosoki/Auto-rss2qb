## 一、schema：一条 revision 干两件事（E-48 + E-49），三条守卫盯着它（E-6 / E-7 / E-1）

**revision `c9a4f1e2d7b3`**：两张种子表加 `prev_status`（TEXT，可空）；drop `ix_anime_alias_title` 与
`ix_sourcegroup_name`。逐步幂等（MySQL 上 DDL 隐式提交、版本号最后才写）；离线 `--sql` 可渲染。

**E-7 的守卫当场抓到我自己**：第一版 `prev_status` 在 revision 里是 `VARCHAR(32)`，而模型经 `adapt_metadata`
定型成 `TEXT`（非索引 str 列一律 TEXT）。回放器把离线脚本回放成表/列/索引终态、逐列与模型比类型族 ——
红了。改到与 `status` 同型。这正是 E-7 要挡的形状（"改了模型没开 revision / revision 写错"），第一次跑就有收益。

**E-6**：以前的守卫按【单列】×4 ≤ 767 算，而 `uq_alias_title_season = (title, season)` 两列：191×4 + BIGINT 8 = **772**，
它自己就超过 767 —— 那条守卫守的是一个早就没守住的承诺。现在按 alembic 产物、逐个索引求全列字节和 ≤ 3072，

**不支持 COMPACT/REDUNDANT 行格式**；顺带纠正了一处算错（season 按 4 字节算成 768，实际 BIGINT 8）。

**E-1（B）**：两个**分开的**空库各自 `upgrade(role)` 到 head，核终态（meta 只有 setting、data 只有六张业务表、
列集合与模型一致）。变异 M31：把 c9a4 的闸抄反成 `!= "meta"` → AST 守卫仍绿（它只看"有没有 role 判定"）、

**E-50**：`db.MYSQL_DDL_LOCK_WAIT_TIMEOUT = 60`，`_ddl_engine` 挂 connect 事件 `SET SESSION lock_wait_timeout = 60`。

## 二、E-49：光加一列还不够

拍板的是"加 `prev_status`，复位时按它还原"。做的时候发现：进锁占位那一段**同时清掉了** `archived_at` 与四个 qB
实时态（为了"作为全新在下重新跟踪"）。崩溃后就算知道原状态是 `sent`，归档标记与 progress=1 也已经没了 ——
还原出来的是一条 sent + progress 0 + 无归档标记的行，下一轮 sync 找不到 hash 就把它打成 error。

所以清理**挪到交付成功那一刻**（写 save_path 那段）。占位段只改 status + 记 prev_status。失败路径的 `_keep_orig`
照旧整组放回（await 期间 sync 可能碰过那几列）。两个复位点（运行中的 `sweep_stale_delivering`、启动时的
`reset_downloading`）共用 `_restore_from_placeholder`。

用例：4 种原态 × 2 条线，取种的 await 里抛 `BaseException` 模拟进程死掉 → 清扫 → 六个字段逐个与占位前相等。
M29（还原一律 pending）/ M30（剧场版占位时又清 archived_at）都红。另加一条 AST 守卫钉住"清理只许出现在
save_path 回写之后"—— 行为用例跑不到成功路径，挡不住有人把那两行加回锁里。

## 三、E-3：三个来源、两条线、一个 tooltip

`qB 消失 → 宽限到点` 的终局：`qb_progress > 0` 落 stalled（盘上有半成品），`== 0` 落 error。这是 E-19 原则的最后一块。
配套三件：
1. 三段互相矛盾的注释对齐（"最终判 error —— 那才是可换源、可补下的结局"那句改掉）。
2. **三个产生 stalled 的地方**都写 `fail_reason`（qB 报错 / N 分钟无推进 / 从 qB 消失·已下 x%）；两条线的详情页
   stalled 徽标都有 tooltip：原因 + "停滞集不会自动重下/换源：要重试点『下载』，要放弃点『删除』"。
   剧场版那页原来对任何 `fail_reason` 都改成橙色"上次失败" —— 对 stalled 要分叉，颜色留 deep-orange。
3. GLOSSARY §十七 把"已接受的代价"写下来：下到 99% 被删的种子停在 stalled 等人工，不自动换源。

两条原来断言 error 的用例改成 stalled（夹具里 progress=0.4），另加"progress=0 仍落 error"与"三处都写原因"。
